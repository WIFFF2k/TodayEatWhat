# 迩灵邑页面

资源栏展示服务端计算的 `productionPerTick`，单位为每 120 秒自动产出预估；页面使用总览的 `serverTime` 校准世界首领、天地异动、护盾和操作冷却倒计时。

页面消费 `/api/realm/overview` 读取当前视口的六边形地块，操作通过服务端接口完成；`/api/realm/gather` 负责鼠标点击采集四类基础资源，`/api/realm/relics/explore` 负责探索遗迹。地图使用轴向坐标和 CSS 六边形按钮呈现，支持方向移动和 q/r 坐标直达，视口移动后重新请求坐标范围，不在浏览器保存世界状态。总览中的 `activities.relics` 是当前玩家完成的遗迹探索次数，`actions` 是最近天下动态，建筑按钮按地块地形筛选。功法升级面板直接使用总览的 `techniqueUpgrade` 显示下一等级费用，费用按目标等级递增。联盟战争面板显示当前玩家累计积分和 `ownRank` 本盟名次，名次按积分降序、用户名升序计算。世界首领击杀后总览会持续返回个人最终排名和奖励，前五名的最终榜单也会显示奖励。赛季到期后服务端自动结算，领地榜和修炼榜前三名分别获得一次性奖励，奖励会写入历史快照，页面展示上一赛季双榜前三及奖励，并可展开查看更早赛季的双榜魁首；点击毁灭世界会清空迩灵邑运行态数据并回到第一赛季

页面支持向其他玩家和联盟仓库捐赠粮食、木材、矿石、灵息四类资源

建筑达到 3 级后可以在地块面板选择一次专精：丰产专精强化自动产出，灵技专精强化主动技能收益，镇守专精强化防御与护盾持续时间

玩家首次进入后可在灵根觉醒面板选择一条修炼路线，选择后会持续获得对应被动加成

页面同时提供本命功法选择与升级入口，功法最高 5 级

修炼面板会显示下一次突破所需的修炼经验、灵息、吃饭次数、发帖次数、遗迹次数和当前成功率；境界谱可展开查看全部大境界、五段小阶段和当前进度

页面侧栏展示限时世界首领的共享血量、个人伤害、个人当前排名和贡献榜，可直接发起围猎；首领每小时生成一场，每场持续 45 分钟，击杀后按贡献发放奖励，面板显示本场剩余时间，地图会在首领坐标显示“王”标记，面板提供“前往首领”按钮。首领空窗期根据总览的 `worldBossNextAt` 显示下一场预计开始时间。侧栏同时保留当前玩家最近攻防战报，显示对手、坐标、成败和掠夺资源

迩灵邑页面每 15 秒同步一次当前视口和世界动态；页面不可见、用户正在输入或正在提交操作时会暂缓同步，离开页面后自动停止。侧栏显示最近 90 秒活跃的局域网修士、最近活跃时间并标记当前玩家，便于确认多人同步状态。赛季结束时，邑城榜和修炼榜前三名分别获得对应奖励

页面侧栏展示每日悬赏，每天轮换五项目标；完成采集、修炼、扩张、建设、探索、捐赠、事件或首领行动后，可以领取当天对应奖励

天地异动支持一次性参与和分支选择；“天灾预兆”可以选择献粮赈灾或炼制护符，不同选择消耗和奖励不同，页面会在选项上显示收益摘要、协作进度、剩余时间和达成目标后的额外奖励，每位玩家每轮只能选择一次。每轮事件有稳定坐标，地图会用“异”标出事件所在地块，并提供“前往异动”按钮直接跳转视口

联盟面板支持盟主发起结盟或停战申请；目标盟主接受后双方不能互相攻击或宣战，任一盟主可以主动解除已经生效的关系。公共工程支持选择个人粮食或联盟仓库粮食投入，并展示各工程的成员累计贡献与投入来源

交易所支持玩家发布 24 小时托管订单，用一种资源换取另一种资源；订单成交时双方资源原子交换，卖方可以取消未成交订单，逾期订单会自动退款

首领会按周期轮换不同种类并显示当前阶段和承伤比例，血量降低后会进入特殊阶段，围猎伤害随阶段规则变化

首领战报同时展示个人贡献榜和联盟贡献榜，联盟名称取攻击发生时的快照

击杀后联盟前三名会获得仓库奖励，页面展示奖励内容和是否已经入仓；历史待领取奖励会列出每笔资源明细，领取后提示实际入仓笔数

联盟面板会显示历史待领取奖励，任意成员都可以将其领取入仓

围猎按钮在个人冷却到期后恢复，击杀后的最终战报保留到本场结束，最后一击展示本次伤害与击杀提示
世界事件卡片会额外标记本轮对主动采集或修炼的数值加成，分支事件仍显示各自的消耗和奖励

建筑手册下方展示服务端计算的修士功勋；达到目标后可直接领取一次性资源或修炼经验，领取后按钮会变为已领取状态

当前功勋包含勤修不辍、悬赏达人、遗迹行者、境界初成、同道相交、战争功臣、守土有责、功法大成、交易行家、济世扶危、应天行者、应变百策、共建联盟、魁首留名、世界猎手、开疆先锋和百工大师，共 17 项；交易行家只统计真实成交的资源交易，济世扶危只统计向其他玩家的捐赠，应天行者和应变百策只统计已结算的事件参与，共建联盟只统计联盟仓库捐赠，魁首留名只统计已归档赛季的双榜第一，世界猎手只统计已完成的世界首领攻击，开疆先锋只统计成功圈地日志，百工大师只统计成功建造日志，守土有责只统计成功守城战报
观星台建在平原上，主动技能提供修炼经验；多座观星台按建筑等级累加提高天地异动的参与奖励，服务端统一封顶 40%。
选中自己的功能建筑后可以拆除，返还基础建造材料的 50%；拆除不会返还升级和专精投入，也不能拆除出生邑城。
御兽苑建在平原上，主动技能提供矿石与灵息，并按建筑等级提高攻击成功率，累计最多提高 15%。
建筑手册顶部会显示当前玩家的天地异动奖励加成，来源于所有观星台的实际等级。
天地异动事件池新增“灵脉迁徙”，玩家可以在追踪矿精和稳固阵眼之间选择一条路线。
事件池新增“天材地宝”，玩家可以在凝神灵草和灵果之间选择不同的消耗与收益。
功勋列表新增“应变百策”，完成 5 次天地异动后可以领取一次性奖励。
功勋列表新增“守土有责”，成功守住领地 3 次后可以领取一次性奖励。
修炼面板会显示当前护盾剩余时间；出生护盾、成功失守后的战后护盾和玄甲营主动护盾统一展示，取实际较晚结束时间。
建筑手册顶部会显示服务端统计的成功守城次数，与“守土有责”功勋进度保持一致。
建筑手册顶部还会显示成功守城与失守次数，数据来自服务端攻防战报聚合统计。
