# 今日空战小游戏

`views/page.js` 将服务端转盘结果接入 Canvas 飞机大战玩法，场景中持续生成大量移动敌机，敌机名称来自独立失败结果池，碰撞后立即锁定该名称为本局结果；完成航线后会出现终点跃迁星门，玩家触碰星门才会领取最终结果

页面通过 `application/router.js` 注册，通过 `application/session.js` 添加侧栏入口；样式只在 `styles/game.css` 中维护

玩家可使用方向键或 WASD 上下左右自由移动，战机会自动连续发射；手机端拖动屏幕控制战机；战机和敌机由本地 WebGL 立体网格及光照绘制，激光、爆炸和滚动星空由 Canvas 绘制，不依赖外部图片资源

失败结果池是独立的共享数据，位于今日空战卡片下方，支持新增、勾选、重命名和删除；最多保存十个结果，每个结果持有稳定的敌机颜色槽位，启用的结果会生成对应敌机并在失败时锁定。难度分为新手、简单、中等、困难、地狱，并显示飞机数量、速度、射击间隔、初始血量和任务长度
