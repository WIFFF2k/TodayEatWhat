# 回归检查

依据：用户要求的白名单登录、分类转盘、全局勾选、多人添加、投票设置与通知、历史记录和局域网一键启动

运行 npm test，使用本机 Edge 和独立临时 SQLite，端口为 20281，不访问正式数据库

| 场景 | 操作与预期 |
|---|---|
| 中文登录与名单 | 遍历实际白名单请求接口；浏览器选择刘心怡、刷新后仍登录；非法及编码错误身份拒绝 |
| 多设备选项与转盘 | 两个真实会话；新增长名称、检查添加人和日志、取消勾选同步；抽签接口结果等于页面和记录、指针角度对应中奖扇区 |
| 投票与设置 | 默认单选 60 分钟；从抽签发起；其他会话通知直达；投票、改票、刷新恢复；多选设置仅影响新投票 |
| 截止与事务 | 原始创建时间推进到过去后禁止投票；无票与并列结果；跨投票选项拒绝；故障触发器验证改票整体回滚 |
| 边界与失败 | 空候选、单候选、重复名称、字符串启用状态、非法分钟；网络失败恢复勾选、未提交表单不被同步清空 |
| 手机与文字安全 | 390px 和 320px 下所有页面无横向溢出；新增 HTML 作为文字显示且不执行 |
| 历史与启动 | 超过 30 条可翻页且旧投票可直接参与；重复启动同实例退出成功；重启后数据仍在 |

所有展示断言使用真实 API 产生的数据，未预填票数与转盘结果；截止通过仅修改临时库的原始创建时间模拟，事务失败通过仅在临时库设置触发器模拟
