# 服务端

`routes.js` 负责身份与选项、转盘、设置入口，`poll-routes.js` 负责投票与记录入口，`repository.js` 集中处理数据库查询、事务和时间转换，`db.js` 初始化数据库

所有时间按亚洲上海时区返回毫秒时间戳，投票方式与时长在创建时保存快照，修改设置只影响新投票

默认数据库位于项目 `data` 目录，自动化检查通过 `DATA_DIR` 指向独立临时目录
选项接口由 option-routes.js 管理，新增、重命名和软删除与 option_logs 留痕在同一事务提交，日志按 ID 游标每页读取 30 条；已有转盘和投票保留原名称，旧选项自动补充原添加人和添加时间
