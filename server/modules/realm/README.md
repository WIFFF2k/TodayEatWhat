# 迩灵邑

主动采集每秒最多一次，基础动作同时获得粮食、木材、矿石和灵息；当前世界事件会在此基础上叠加对应资源或修炼经验加成

每日悬赏从任务池轮换五项目标，复用行动日志统计当天进度；完成后通过按玩家、日期和任务键保存的凭证领取一次性资源与修炼经验奖励

联盟外交支持结盟和停战申请，申请由目标盟主接受或拒绝；生效关系会阻止双方攻击和宣战，关系按联盟 ID 持久化并随联盟解散级联清理

玩家交易采用 24 小时有效的资源托管订单，挂单时先扣除卖方资源，成交时原子交换双方资源，取消或过期订单会退回托管资源

迩灵邑是局域网共享的持续发展世界，服务端保存世界种子、六边形地块、玩家资源和修炼进度

个人捐赠和联盟仓库捐赠支持粮食、木材、矿石、灵息四类资源，接口未指定资源时默认捐赠粮食

玩家首次进入后可以选择一次灵根道途：厚土灵根强化粮食和木材，百炼剑骨强化矿石与攻击，天灵根强化灵息与修炼经验；觉醒结果持久化且不可重复选择

世界事件包含“兽潮来袭”协作目标，至少五名不同玩家参与后完成目标，最后完成目标的玩家获得额外战功奖励，每位玩家仍只能参与一次

世界事件也支持分支选择；“天灾预兆”按 `payload.choices` 定义选择键、资源消耗和奖励，服务层校验选择与资源后在参与记录事务内结算，每位玩家每轮只能选择一次

玩家可以选择一门本命功法并升级至 5 级：厚土载物诀强化资源获取，太虚纳气诀强化修炼经验，玄锋战诀强化攻击与突破成功率；功法升级按目标等级递增消耗修炼经验和灵息，第 N 级需要 `300×N` 修炼经验与 `10×N` 灵息

修仙境界当前按炼体、练气、筑基、金丹、元婴、化神、炼虚、合体、大乘、渡劫、真仙、金仙、太乙、大罗、道祖十五个大境界推进，每个大境界统一包含初期、中期、后期、半步圆满、圆满五个阶段；达到当前世界最高境界后仍可继续积累修炼经验，新增境界只需扩展 `STAGES` 配置并沿用突破材料计算

攻击成功后会从防守方各类资源中掠取 8%，并与地块归属变更在同一事务中结算；攻防战报会保留本次是否获得联盟战争积分，玄甲营防御和新城护盾仍然有效

同一联盟成员不能互相攻击；跨联盟攻击会受到外交关系、战争状态、攻击冷却和出生护盾共同约束

盟主可以向其他联盟宣战，战争持续 24 小时；战争期间成功攻击敌对联盟成员会为己方增加 1 点战争积分，页面会显示双方积分和结束时间

战争进行期间禁止退出联盟、转让盟主和解散联盟，避免绕过战争积分与结算规则

战争到期后首次访问会按积分判定胜者，胜者联盟仓库获得粮食、木材、矿石和灵息奖励，并由当前盟主写入 `war-warehouse-reward` 天下动态；个人贡献前三会获得个人奖励并写入天下动态；平局不发放胜利奖励，结算记录只处理一次

联盟面板保留最近五场战争记录，显示进行中、胜利、失利或平局状态、最终积分和进行中战争的剩余时间；本盟获胜的历史记录同时显示联盟仓库结算资源 `warehouseReward`
战争记录同时展示本盟参战贡献前三和当前玩家自己的累计贡献及 `ownRank`；`ownRank` 仅在玩家已有成功计分记录时返回，按积分降序、用户名升序计算；本盟获胜且当前玩家进入个人贡献前三时，记录会返回 `ownReward`（名次、粮食、木材、矿石、灵息和修炼经验）并在面板展示；成功攻击计入战争积分时，操作反馈会明确显示本次新增积分；同一对手战争结算后需等待 24 小时才能再次宣战

世界首领按 1 小时周期出现，每场持续 45 分钟并共享血量，场次之间保留 15 分钟准备间隔；玩家消耗矿石和灵息进行围猎，伤害前五名获得额外资源与修炼经验，所有参战者获得基础奖励，奖励标记保证只发放一次
击杀响应会返回 `bossRanking` 最终战报；每项包含最终 `rank` 和实际 `reward`，击杀者另外获得 `bossPersonalRank`、`bossPersonalReward`，用于立即展示自己的名次和奖励；个人奖励发放会写入天下动态并按参战记录幂等处理

世界首领按周期轮换九幽镇界兽、赤炎涅槃凰和太古玄岳龟三种模板；血量进入不同阈值后切换狂怒、涅槃或玄甲阶段，实际承伤倍率随阶段变化

联盟公共工程新增“猎界战旗”，每级提高成员对世界首领的伤害 10%，与通天商路、共修道场共用投入和升级机制；投入来源支持个人粮食或联盟仓库粮食，仓库投入不会重复计入个人贡献，并按工程保存成员投入来源与累计贡献榜

首领参战记录保存攻击时的联盟名称快照，页面同时展示个人伤害、个人当前排名和联盟伤害榜，退盟或解散不会改写已经产生的首领战报

首领击杀后按联盟伤害前三名向仍存在的联盟仓库发放粮食、木材、矿石和灵息；奖励凭证独立保存，联盟不存在时明确记录为未入仓

联盟成员可以从联盟面板领取历史未入仓奖励，领取动作按奖励凭证幂等处理，多个成员同时操作不会重复入仓

新增平原建筑“灵市”，可以消耗木材、矿石和灵息主动兑换粮食；建筑技能支持独立消耗资源，后续交易类建筑可复用同一规则

地图使用轴向六边形坐标 `(q,r)`，只在玩家读取或操作时生成地块；省略视口坐标时以玩家出生点为中心。圈地只要求与己方地块相邻，不设置距离出生点的终点，玩家可以沿连接领地持续扩张到远方区域。攻击结果会保存为双方可见的最近攻防战报，包含坐标、成败和掠夺资源。服务层负责规则与事务编排，仓储负责数据库读写，路由只负责接口装配

当前领域包含：资源随时间收集、点击采集、领地占领、建筑升级与主动技能、建筑专精、遗迹探索、遗迹专属镇魂碑、平原专属玄甲营、修炼阶段与突破、特殊事件参与、世界毁灭调试入口、攻击冷却、出生护盾、行动日志、排行榜、联盟、联盟仓库、盟主转让和解散联盟。自动产出按 120 秒一个周期结算，查询总览不会重复发放；点击采集每秒最多一次，四类基础资源都会获得固定收益，灵根、功法和当前世界事件会共同影响最终增量，接口返回 `gatherReward` 作为本次实际获得量。修炼经验由自动产出、建筑技能和对应事件提供。建筑技能按地块独立冷却：灵谷仓催熟粮食、青木坊恢复木材、玄铁矿探脉、聚灵坛和镇魂碑同时提供灵息与修炼经验、玄甲营短时提供护盾。建筑达到 3 级后可以消耗木材、矿石和灵息选择一次丰产、灵技或镇守专精，分别强化自动产出、主动技能收益或防御与护盾持续时间。世界事件按 30 分钟周期从十三种模板中轮换，包含天门论道等多人协作目标；事件生成在事务内二次检查，避免并发重复创建；每轮世界事件每位玩家只能参与一次，事件奖励通过参与记录防止重复领取；攻击夺地使用目标归属条件更新，掠夺资源与双方状态在同一事务内结算，避免并发攻击覆盖或奖励丢失；每块遗迹允许每位玩家独立探索一次，距离出生邑城越远奖励越高，探索次数通过总览 `activities.relics` 返回并作为高阶突破材料。联盟公共工程按实际投入量连续结算等级，不会因一次大额投入跨过多个门槛而损失进度。突破材料通过 `records` 与 `memories` 领域仓储接口读取真实吃饭决策次数和回忆帖次数，每次突破分别校验两类次数，不能用单一活动替代另一类。七天赛季到期后首次访问会自动保存排行榜快照、给前三名发放一次性资源和修炼经验并开启下一赛季，玩家领地、资源和修炼保留；历史排名中的 `seasonReward` 是结算凭证。点击“毁灭世界”会清理迩灵邑玩家、地块、联盟、事件及事件参与记录、动态和赛季历史，并将赛季编号重置为 1；联盟公共工程 key 固定为 `road`、`academy` 和 `hunt`
修炼榜按大境界、小阶段和修炼经验排序，和领地榜并列展示，避免只靠扩张面积衡量玩家成长；赛季历史同时保存两套榜单，上一季的邑城魁首和修炼魁首都会保留，两个榜单前三名分别获得对应奖励，同一玩家可以同时领取两套奖励

总览中的建筑配置同时返回建造成本与技能消耗、奖励，前端建筑手册直接使用这份服务端配置，新增建筑无需重复维护成本文案

建筑升级费用由服务端统一按当前等级计算：升至下一级需要 `25 × 当前等级` 木材和 `floor(12.5 × 当前等级)` 矿石；扣费与冲突校验均使用同一计算函数

前端建筑手册同时展示十七项可追踪修士功勋：勤修不辍、悬赏达人、遗迹行者、境界初成、同道相交、战争功臣、守土有责、功法大成、交易行家、济世扶危、应天行者、应变百策、共建联盟、魁首留名、世界猎手、开疆先锋和百工大师；进度由服务端总览中的活动、每日悬赏、遗迹探索、大境界、联盟状态、战争历史、防守战报、功法等级、交易、捐赠、事件、联盟仓库、赛季历史、世界首领、圈地和建造行动日志统一计算，不额外写入运行态表，前端只负责展示

功勋达成后可通过 `/realm/achievements/claim` 领取一次性资源或修炼经验；领取凭证按玩家和功勋键唯一约束，世界毁灭时一并清理

选中已有建筑时，地图操作面板会直接显示升至下一等级所需的木材和矿石，具体扣费仍由服务端升级规则校验

当前世界事件池为十三种，新增“灵兽认主”分支，玩家可在供养灵兽和签订战契之间选择不同资源消耗与收益
观星台是平原专属功能建筑：主动技能“观星推演”消耗粮食与灵息并提供修炼经验；拥有多座观星台时，天地异动的个人参与奖励和协作完成奖励按各座建筑等级累加提高，服务端统一封顶 40%。
功能建筑可以拆除并返还基础建造成本的 50%，升级和专精投入不返还；镇城不可拆除，拆除操作与资源返还在同一事务内完成。
御兽苑是平原战斗建筑：主动技能提供矿石与灵息，建筑等级会提高攻击成功率；多座御兽苑累计加成最高 15%，由服务端在攻击结算时计算。
总览字段 `worldEventBonus` 会返回当前玩家所有观星台的累计事件奖励加成，最高为 40%。
事件池现包含十三种模板；“灵脉迁徙”提供追踪矿精与稳固阵眼两种互斥选择，沿用每轮每人一次参与和服务端奖励结算规则。
事件池现包含十三种模板；“天材地宝”提供凝神灵草与灵果两种互斥采集路线，分别偏向修炼经验和基础资源。
功勋当前包含十七项；“应变百策”按真实天地异动参与日志统计，完成 5 次后通过永久领取凭证发放奖励；“守土有责”按真实攻防战报统计成功守住领地 3 次，奖励粮食、矿石和修炼经验。
普通攻城成功后会给失守玩家发放 45 秒战后护盾；该护盾与出生保护、玄甲营护盾取较晚结束时间，不会覆盖更长的已有保护。
总览中的 `defenseWins` 与 `defenseLosses` 由攻防战报聚合查询生成，分别表示成功守城和失守次数；防守功勋只使用 `defenseWins`。
